# Python Calculator

A command-line calculator with full error handling.

## Files
- `calculator.py` – core logic (raises `CalculatorError` on any problem)
- `main.py` – interactive command-line interface
- `test_calculator.py` – unit tests (`unittest`, no extra packages needed)

## Run in VS Code
1. Open this folder: **File → Open Folder…**
2. Install the **Python** extension (VS Code will recommend it).
3. Press **F5** (or open `main.py` and click ▶ Run) to start the calculator.
4. Open the **Testing** panel (beaker icon) to run the tests.

## Run from the terminal
```
python main.py
python -m unittest -v
```
